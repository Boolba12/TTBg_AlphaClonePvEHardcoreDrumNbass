# Commander portraits

Place one commander image per file in the race folder:

- `Humans`
- `Elves`
- `Dwarves`
- `Orcs`
- `Tieflings`

The folder determines `CommanderRace`; filenames do not. Run
`Tools/Commander Portraits/Rebuild Database` after adding images. Changes inside
these folders also schedule an automatic rebuild.

The generated database is:

`Assets/Art/CommanderPortraits/CommanderPortraitDatabase.asset`
